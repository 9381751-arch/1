# Каркас·КМ — экспресс-расчёт стального каркаса здания

Онлайн-калькулятор одноэтажного производственного/складского здания: подбирает сечения
рамы, фермы, балки, прогонов и связей, рисует схему поперечной рамы и план осей,
считает общий тоннаж металла. Нагрузки по умолчанию — Санкт-Петербург
(снеговой район III, ветровой II, тип местности B).

Открыть: `index.html` — один самодостаточный файл, без сборки и зависимостей.

## Что вводится

| Группа | Параметры |
|---|---|
| Габариты | пролёт, число пролётов (1–3), шаг колонн, длина здания, высота до низа ригеля |
| Кровля и ригель | двускатная / односкатная / плоская, уклон, балка или ферма |
| Ограждающие | сэндвич (PIR / PUR / минвата + толщина) или профлист — отдельно кровля и стены, кровля по прогонам или панель по рамам |
| Кран | нет, подвесная кран-балка 1–5 т, опорный мостовой 5–32 т |
| Нагрузки | снеговой и ветровой район, тип местности, c<sub>e</sub>, неравномерный снег, марка стали, уровень ответственности |

Плоская кровля + ферма → автоматически **ферма «Молодечно»**: пояса из тавров,
решётка из круглых труб, бесфасоночные узлы.

## Что выдаётся

* Схема поперечной рамы с осями, размерами, уклоном, краном и выносками сечений.
* План осей со связевыми блоками и шагом рам.
* Ведомость металла: профиль, длина, количество, масса, использование сечения.
* Нагрузки (кровля, прогоны, снег, ветер, кран) и все проверки.
* Общий тоннаж и расход, кг/м²; сравнение «балка ↔ ферма» по массе.

Три схемы подбора переключаются на месте:

| Схема | Использование сечений | Гибкость колонн | Связи / узлы |
|---|---|---|---|
| Минимальная | до 98 %, учтён пластический ресурс балок | λ ≤ 120 | 4 % / 8 % |
| Оптимальная | 85 %, упругая работа | λ ≤ 110 | 5 % / 10 % |
| С запасом | 70 % | λ ≤ 100 | 6 % / 12 % |

## Расчётные предпосылки

* Нагрузки — СП 20.13330.2016: снег `S₀ = 0,7·cₑ·cₜ·μ·S_g`, ветер `w = w₀·k(zₑ)·c`
  (средняя составляющая, наветренная 0,8 + подветренная 0,5). Прогибы — от постоянных
  и пониженного значения снеговой нагрузки (0,5·S), предельные — по табл. Д.1.
* Устойчивость — СП 16.13330: φ по формуле п. 7.1.3 (тип сечения b), внецентренное
  сжатие колонн проверяется упрощённо суммой `N/(φA) + M/W ≤ R_y`.
* Рама с балочным ригелем — жёсткий карнизный узел, шарнирные базы; распор
  `H = qL²/(4H(2k+3))` по соотношению жёсткостей ригеля и колонны (итерация по
  собственному весу).
* Ферма — шарнирное опирание, колонна защемлена в базе; усилия в поясах `N = M(x)/h`,
  в решётке `N = V/sin α` по панелям.
* Сортамент: ГОСТ 26020-83 (Б, Ш), ГОСТ 30245-2003 (гнутосварной квадрат),
  ГОСТ 10704-91 (трубы), Z-профили ЛСТК, швеллеры.

## Границы применимости

Расчёт **предварительный** — для оценки тоннажа и компоновки на стадии КМ/ТКП.
Не выполняются: местная устойчивость стенки и полок, расчёт узлов, баз и монтажных
стыков, температурные блоки, пульсационная составляющая ветра, прогрессирующее
обрушение, сейсмика. Перед выпуском КМ результат проверяется расчётом в ПК
(SCAD / Лира / IDEA).

## Разработка

Расчётное ядро в `index.html` выделено маркерами `//<ENGINE>` … `//</ENGINE>`
и не обращается к DOM, поэтому его можно тестировать в node:

```sh
awk '/^\/\/<ENGINE>$/,/^\/\/<\/ENGINE>$/' index.html > engine.js
echo "module.exports = {compute, SCHEMES, phi};" >> engine.js
```

## Публикация

Страница статическая — один файл `index.html` без сборки, поэтому годится любой
веб-сервер: положить файл в веб-корень и открыть.

В репозитории заведены два способа автоматической выкладки при пуше в `main`:

* `.github/workflows/pages.yml` — GitHub Pages, адрес вида
  `https://<owner>.github.io/<repo>/`. Требуется один раз включить Pages
  (Settings → Pages → Source: GitHub Actions).
* `.github/workflows/deploy-server.yml` — rsync по SSH на собственный сервер.
  Включается переменной `DEPLOY_ENABLED=true` и секретами `DEPLOY_HOST`,
  `DEPLOY_USER`, `DEPLOY_PATH`, `DEPLOY_SSH_KEY` (плюс необязательные
  `DEPLOY_PORT`, `DEPLOY_KNOWN_HOSTS`) в Settings → Secrets and variables → Actions.
  Ключ задавайте отдельный, только для деплоя.
