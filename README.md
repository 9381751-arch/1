# АЗИМУТ — автоматизация закупки б/у шпунта

Система автоматизации полного цикла закупки б/у шпунта: от парсинга заявки клиента
до выбора поставщика менеджером.

## Архитектура

```
TG-канал заявок ──▶ Бот (aiogram) ──▶ Claude API (парсинг)
                          │
                          ├──▶ Supabase (БД)
                          │
                          ├──▶ TG-группа продавцов (публикация поста)
                          │
                          ├──▶ OSRM (расстояния) ──▶ расчёт себеса
                          │
                          ├──▶ Личка ТОП-3 продавцов (торг)
                          │
                          └──▶ Личка менеджера (итоговый отчёт)

Веб-дашборд (Next.js) ──▶ Supabase ──▶ Управление, настройки, ручной ввод
```

## Структура репозитория

```
.
├── bot/              Python aiogram бот (M1–M6)
├── dashboard/        Next.js 14 + shadcn/ui веб-дашборд
├── supabase/         SQL миграции и seed
├── .env.example      Шаблон переменных окружения
└── README.md
```

## Модули бота

| Код | Назначение |
|-----|------------|
| M1  | Парсинг заявки клиента из TG-канала через Claude |
| M2  | Публикация поста в группу продавцов |
| M3  | Сбор предложений (группа + личка), парсинг через Claude |
| M4  | Расчёт себестоимости (цена + логистика OSRM) |
| M5  | Торговый раунд с ТОП-N продавцами |
| M6  | Итоговый отчёт менеджеру с inline-кнопками выбора |

## Быстрый старт

1. Скопировать `.env.example` в `.env`, заполнить значения.
2. Применить миграции Supabase: `supabase db push` (или вручную в SQL editor).
3. Запустить бота: `cd bot && uv run python -m src.main`.
4. Запустить дашборд: `cd dashboard && pnpm dev`.

Подробности — в `bot/README.md` и `dashboard/README.md`.

## Стек

- **Бот**: Python 3.11, aiogram 3, anthropic SDK, supabase-py, httpx
- **Дашборд**: Next.js 14 (App Router), TypeScript, shadcn/ui, Tailwind, Supabase Auth
- **БД**: Supabase / PostgreSQL
- **LLM**: Claude API (`claude-sonnet-4-6`)
- **Логистика**: OSRM (open source)
- **Хостинг**: дашборд — Vercel; бот — Railway / VPS
